# Portfolio Use Case

A fictional operations team asks the system to prepare an AI exception-handling
checklist. The agent retrieves approved control notes, drafts the checklist, and
then pauses. A human reviewer approves or rejects it. Only approval causes the
system to write the final Markdown artifact.

The demo measures run count, approval status, drafting latency, source attribution,
and estimated model cost. Local Ollama inference is recorded with zero API cost.
