# AI Control Principles

Probabilistic components may retrieve context, classify requests, propose plans,
rank options, and draft artifacts. Deterministic application code must validate
permissions, enforce state transitions, persist approved outputs, and record the
audit trail.

High-impact actions require a named human reviewer. The reviewer should see the
objective, sources, draft, assumptions, and quality checks before deciding.
